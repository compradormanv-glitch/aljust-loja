Al.just — Categorias fechadas + Stock do proprietário + Conta do cliente (V7)

1. Página pública
- "Todas as categorias" abre o menu de categorias/subcategorias.
- As categorias não ficam expostas permanentemente na página inicial.
- A quantidade exata de stock não aparece para clientes; o público vê apenas "Disponível"/"Esgotado" conforme o produto.

2. Conta do cliente
- Botão "Entrar" no cabeçalho.
- Entrar com e-mail e palavra-passe via Supabase Auth.
- Criar conta.
- Recuperar palavra-passe por e-mail.
- Nome da conta guardado como metadata do utilizador.
- O checkout exige sessão iniciada antes de continuar.

3. Proprietário
- Acesso ao admin continua pelos 5 cliques no logotipo.
- O admin pede login e reautenticação nas ações protegidas.
- Stock, alertas de stock baixo e histórico continuam no admin.

4. Nota Supabase Auth
Para recuperação de palavra-passe, o URL publicado da página precisa estar autorizado em:
Supabase > Authentication > URL Configuration > Redirect URLs.
Exemplo do GitHub Pages:
https://SEU-USUARIO.github.io/aljust-loja/

Não coloque service_role key no frontend. O pacote usa apenas a chave publishable/anon existente no projeto.
